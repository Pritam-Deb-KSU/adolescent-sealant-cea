# Adolescent school sealant program model (1M/2M Markov cohort simulation)

Open-source Python model behind **"Impact and Cost-Effectiveness of Adolescent School Sealant Programs"**
(submitted to the *Journal of Dental Research*). It follows the first (1M) and second (2M) permanent
molars of a cohort of 1,000 12-year-olds for 14 half-year cycles (ages 12–19) and compares three
school-based sealant program (SBSP) policies against no program, from the payer (Medicaid) perspective.

Everything reported in the manuscript is regenerated by two scripts:

| Script | Produces | Manuscript item |
|---|---|---|
| `model/sealant_markov_model.py` | `results/Sealant_Markov_Stochastic_Results_submitted.xlsx` (sheet *Table 2 (paper)*), `figure2_cumulative_decay.png`, `figure3_tornado_2M.png`, `figure3_tornado_1M.png` | Table 2, Figure 2, Figure 3 |
| `model/psa_ceac.py` | `results/psa_results.xlsx`, `results/psa_draws.csv`, `figure_psa_ce_plane_ceac.png`, `figure_psa_ceac_multiway.png` | Probabilistic sensitivity analysis, cost-effectiveness acceptability curves, implementation scenario (revision) |
| `model/figure3_abc.py` | `results/figure3_abc.pdf` (vector) and `.png` (600 dpi) | Figure 3 with the probabilistic sensitivity analysis as panel (c) (revision) |

Both scripts are deterministic (fixed seeds) and self-check: `sealant_markov_model.py` compares every
Table 2 cell and every Figure 3 value it produces with the submitted manuscript and prints
`62/62 cells identical` / `26/26 values identical`.

## Quick start

```bash
git clone https://github.com/<org>/adolescent-sealant-cea.git
cd adolescent-sealant-cea
python -m venv .venv && source .venv/bin/activate     # optional
pip install -r requirements.txt
python model/sealant_markov_model.py    # ~1 s:  Table 2, Figures 2–3
python model/psa_ceac.py                # ~5 s:  PSA, CEACs, implementation scenario
python model/figure3_abc.py             # ~5 s:  Figure 3 (a, b as submitted + new panel c), vector PDF
```

Outputs are written to `results/`. Python ≥ 3.9; dependencies are `numpy`, `openpyxl`, `matplotlib`, `pypdf`
(`pdftoppm` from Poppler is used, if installed, for the PNG preview of Figure 3).

## Model

**States** (per tooth): sound sealed (S), sound not sealed (NS), untreated decay (C), filled (F, absorbing)
and, for 2M only, not yet erupted (NE). Each 6-month cycle:

* S → S with the retention probability R; S → NS with (1−R)(1−AR/2); S → C with (1−R)(AR/2)
  (a lost sealant is assumed lost at mid-cycle, so the tooth is exposed for half a cycle).
* NS → C with the 6-month attack rate AR (tooth-type specific); NS → NS otherwise.
* C → F with the age-specific probability of a dental visit (annual MEPS probability ÷ 2);
  all untreated decay is filled at the visit.
* NE → NS on eruption (NHANES-derived schedule); an erupted tooth becomes susceptible in the next cycle.

**Cohort at age 12** (per 1,000 12-year-old adolescents, 4,000 teeth of each type; NHANES 2011–16):

| | 1M | 2M |
|---|---|---|
| Sound, sealed | 1,332 | 528 |
| Sound, unsealed (eligible) | 1,696 | 2,136 |
| Unerupted | 0 | 1,148 |
| Already decayed / filled / missing (not modelled) | 972 | 188 |

**Scenarios**

| | 2M | 1M |
|---|---|---|
| No sealants | natural history | natural history |
| Case 1 | seal all eligible 2M at age 12 | natural history |
| Case 2 | as Case 1 | seal all eligible 1M at age 12 |
| Case 3 | Case 2 + reseal lost sealants and seal newly erupted 2M in every cycle of the first two years (ages 12.5–14) | Case 2 + reseal lost sealants, ages 12.5–14 |

**Costs** are Medicaid fee-for-service payments (49.4 % of 2022 ADA survey fees): sealant $33.75/tooth,
restoration $130.89/tooth, discounted at 3 % per year (factor (1.03)^(−t/2) for cycle t).
Net program cost = sealant cost − averted restoration cost relative to no program.

**Uncertainty.** `sealant_markov_model.py` runs the cohort as a stochastic (binomial) microsimulation:
each of 1,000 replications draws R, AR (1M and 2M), the sealant fee and the restoration fee from the
triangular distributions of Table 1, then simulates every transition as a binomial draw. Table 2 reports
the mean over replications with a conventional 95 % CI of the mean (mean ± 1.96·SE); cost-effectiveness
ratios are ratios of means with delta-method CIs. Figure 3(a, b) is a deterministic one-way analysis (each
input ±20 %, others at base value) using the expected-value form of the same model; Figure 3(c) shows the
cost-effectiveness acceptability curves from the probabilistic sensitivity analysis below.
`figure3_abc.py` reuses the submitted Figure 3 PDF (`results/figure3_ab_submitted.pdf`) unchanged for
panels (a, b) and draws panel (c) in the same style (Times, same axes width and text sizes).

`psa_ceac.py` performs the probabilistic sensitivity analysis: 10,000 parameter sets drawn from the
Table 1 distributions (plus a ±20 % multiplier on the dental-visit probabilities) are propagated through
the expected-value form of the model, so the resulting intervals reflect parameter (second-order)
uncertainty only. It produces the cost-effectiveness plane, pairwise CEACs against no program, the
multi-way CEAC and acceptability frontier over the four mutually exclusive strategies, the expected
value of perfect information, and an **implementation scenario** (Case 1 delivered by an SBSP to the cohort
of 1,000 12-year-old adolescents with a Beta-distributed consent rate). Under the payer perspective the consent
rate scales costs and averted decay proportionally, so the implementation CEAC coincides with Case 1's and the
sheet *Implementation* reports the scale of impact and budget. See the docstring at the top of `psa_ceac.py`
and `docs/psa_methods_and_response.md`.

## Reproducibility notes

* Seeds: `SEED = 12345` (microsimulation), `PSA_SEED = 2026` (PSA). NumPy's `default_rng`
  (PCG64) is used throughout; results are bit-reproducible across platforms for a given NumPy ≥ 1.17.
* All model inputs are module-level constants at the top of `sealant_markov_model.py`
  (`AR_BASE`, `R_TRI`, `yearly_visit_probs`, `SEALANT_COST_TRI`, `FILLING_COST_TRI`, `ERUPTION_2M`,
  `SCENARIOS`, `DISCOUNT_RATE`). Changing a value and re-running regenerates every table and figure.
* `IMPL_SCREENING_COSTS` in `psa_ceac.py` (an optional extra program cost per consenting adolescent) is `[0.0]`
  for the manuscript; non-zero values are for exploration only.
